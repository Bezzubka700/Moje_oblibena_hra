# Battlefield 6 - Příručka přežití
## Úvod
*Tohle není obyčejná střílečka.* **Battlefield 6** tě hodí přímo do středumasivního chaosu, kde rozhoduje **týmová spolupráce** a **rychlé uvažování**.

### Tipy pro přežití:
1. Drž se svého squadu
2. Používej zničené prostředí jako úkryt před nepřátelskou střelbou
3. Důkladně si vybírej své cíle
