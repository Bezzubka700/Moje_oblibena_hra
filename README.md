# Battlefield 6 - Příručka přežití
## Úvod
*Tohle není obyčejná střílečka.* **Battlefield 6** tě hodí přímo do středumasivního chaosu, kde rozhoduje **týmová spolupráce** a **rychlé uvažování**.

### Tipy pro přežití:
1. Drž se svého squadu
2. Používej zničené prostředí jako úkryt před nepřátelskou střelbou
3. Důkladně si vybírej své cíle

## Výbava
| Třída | Hlavní role | Výhoda |
| :--- | :--- | :--- |
| **Assalut** | Útok v první linii | Skvělá mobilita |
| **Engineer** | Opravy vozidel | Ničení nepřátelských vozidel |
| **Support** | Zásobování municí | Udržeí týmu v akci |

### Ukázka taktického kódu
```python
def hrac_přežije(stamina, ammunition):
    if stamina > 50 and ammunition > 0:
        return "Úspěšný útok!"
    return "Taktický ústup!"
```

### Stav příprav na boj
 - [x] Munice doplněna
 - [x] Sehnat svojí squadu
 - [ ] Najít vozidlo na transport na bojiště
